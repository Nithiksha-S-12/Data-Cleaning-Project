# Data Cleaning & Visualization Project

## Objective
The objective of this project is to clean raw data and generate meaningful insights using visualization techniques.

---

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset Used
Titanic Dataset from Kaggle

---

## Steps Performed
1. Imported libraries
2. Loaded dataset
3. Explored dataset
4. Handled missing values
5. Removed duplicate rows
6. Removed outliers
7. Performed data visualization
8. Generated insights from charts

---

## Visualizations Created
- Survival Count Plot
- Passenger Class vs Survival
- Age Distribution Histogram
- Correlation Heatmap

---

## Key Insights
- More passengers did not survive.
- First-class passengers had higher survival rates.
- Most passengers were between 20 and 40 years old.
- Fare and passenger class influenced survival.
